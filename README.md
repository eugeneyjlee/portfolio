# Eugene Lee — Growth & Marketing

Personal portfolio for 2027 new graduate opportunities.

**Website:** https://eugeneyjlee.github.io/portfolio/

## Content

A simple introductory screen leads into three featured industry experiences (TikTok, MangoBoost, Chime), seven contracted company projects, and a short biography. Company logos and translucent résumé/email buttons accompany a playful visual style.

## Editing and publishing

- `index.html`: content and links.
- `style.css`: responsive layout and design.
- `reveal.js`: progressive scroll animations. Content remains visible without JavaScript; reduced-motion preferences disable animation.
- `eugene.jpg` and `logo-*`: local image assets.
- `LOGO-SOURCES.md`: logo provenance.

No build step or dependencies. GitHub Pages serves the `main` branch from `/ (root)`.
