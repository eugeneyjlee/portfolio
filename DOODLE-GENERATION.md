# Doodle asset

Tool: built-in image_gen (no CLI).
Asset: dist/doodles.png
Original generated output preserved; transparent alpha used for the site.

## Final prompt
Use case: illustration-story. Create one decorative website asset: a square 2 by 2 sprite sheet of FOUR original hand-drawn black ink doodles, each perfectly centered in its own equal quadrant with generous clear space: top left a cheerful simple sun, top right a five-petal flower with two leaves, bottom left a wobbly outlined five-point star with two tiny sparkles, bottom right a little butterfly. Loose friendly imperfect marker linework, minimal monochrome outlines, no fills, no shading, no textures. Actual transparent alpha background. No text, no logo, no watermark, no grid lines. Each icon must fit entirely inside the middle 60 percent of its quadrant, with no overlap into any adjacent quadrant. This is for sparse playful decorations on a black-and-white personal portfolio. Original designs, not a stock image reproduction.
